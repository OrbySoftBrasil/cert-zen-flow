# Roadmap — Certus AC (protótipo funcional)

- [x] Paginação reutilizável (com itens por página) aplicada às listas grandes
- [x] Classificações de chamado configuráveis (categorias/subcategorias/SLA)
- [x] Base de conhecimento com upload de documento
- [x] Agenda: visão mês com todos os agendamentos + lista de próximos
- [x] Portal público: abertura de chamado com identificação + autoagendamento (estilo Calendly)
- [x] Financeiro integrado: lançar a pagar/receber, planos, contratos, regras de comissão
- [x] Portal do parceiro: anexos no cadastro de cliente e gestão de documentos
- [x] Login, MFA, recuperação e redefinição de senha
